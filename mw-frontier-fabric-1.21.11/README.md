# MW Frontier - Fabric, Minecraft Java 1.21.11 (Module 1)
Space suit + oxygen + low gravity in The End. See the chat for step-by-step build/install.
Needs: Java 21 JDK, Fabric Loader 0.18+ (0.19.5 fine), Fabric API 0.141.3+1.21.11.
Build: copy gradlew, gradlew.bat and gradle/ from the official Fabric example mod for 1.21.11, then `gradlew build`.
Jar: build/libs/mw-frontier-0.1.0.jar
